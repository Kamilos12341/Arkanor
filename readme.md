# Arkanor

### Arkanor to pixel-artowa gra przygodowa 2D inspirowana klasycznymi MMORPG, oferująca eksplorację, interakcje z NPC, zadania oraz walkę w ręcznie stworzonej krainie.
---
### Projekt preznaczony jest na wersję Unity (6000.3.14f1)

## Sterowanie

* WASD lub klawisze strzałek - ruch postaci
* E - interakcja
* Spacja - atak
